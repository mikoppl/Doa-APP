# Cara membuat APK (tanpa install apa pun di komputer)
1. Buat akun gratis di github.com, lalu buat repository baru (New repository).
2. Klik "uploading an existing file", tarik SEMUA isi folder ini (termasuk folder .github), lalu Commit.
3. Buka tab "Actions" > "Build APK" > tunggu sekitar 5-8 menit sampai centang hijau.
4. Buka hasil run tersebut, bagian Artifacts, unduh "Doa-Sehari-hari-APK" (zip), ekstrak, kirim app-debug.apk ke HP.
5. Di HP, buka file APK dan izinkan "Install dari sumber tidak dikenal" jika diminta.
